# 轻照（LitePhoto）

纯前端证件照 / 图片处理工具。裁剪、缩放、旋转、翻转、压缩、证件照规格与排版尺寸全部在浏览器本地完成，**不上传图片，不需要后端服务**。

- 技术栈：原生 HTML / CSS / ES Module + Canvas 2D
- 构建：Vite（与主站共用一次构建，运行时零依赖）
- 测试：Vitest + Playwright（系统 Edge）
- 适配：桌面三栏工作台 / 手机 H5 单栏 + 底部工具标签

## 快速开始

要求 Node.js **^20.19.0 或 >=22.12.0**（Vite 8 的要求）。

在 **仓库根目录** 执行：

```bash
npm install
npm run dev
```

- 主站：`http://localhost:5173/lite-joy/`
- 轻照：`http://localhost:5173/lite-joy/image-tool/`

生产构建：

```bash
npm run build
npm run preview
```

构建产物在根目录 `dist/`，轻照页面位于 `dist/image-tool/`，随主站一起发布到 GitHub Pages。页面使用 `/lite-joy/` 作为 base，资源路径会自动加上前缀；应用本身没有前端路由，不需要 `try_files` 回退。

## 功能

### 基础编辑

- 拖入、粘贴、文件选择或手机拍照导入 JPG / PNG / WebP，单文件上限 40 MB。
- 自由裁剪：拖动 8 个手柄，或切换到「调整选框」整体移动裁剪框。
- 固定比例：原图、1:1、3:4、4:3、16:9；固定比例下通过拖动照片改变构图。
- 移动照片、滚轮缩放、双指捏合、双击缩放、「适应画布」。
- 左/右旋转 90°、水平/垂直翻转、-180°～180° 微调角度。
- 「重置裁剪」「重置变换」分别恢复构图与旋转状态。

### 证件照规格

| 一寸 | 295×413 | 300 | — |
| 小一寸 | 260×378 | 300 | — |
| 大一寸 | 390×567 | 300 | — |
| 二寸 | 413×579 | 300 | — |
| 小二寸 | 413×531 | 300 | — |
| 大二寸 | 413×626 | 300 | — |
| 公务员 | 295×413 | 300 | — |

| 社保 | 358×441 | 350 | 14–40 KB |
| 教资 | 295×413 | 300 | — |
| 考研 | 480×640 | 300 | — |
| 护照 | 390×567 | 300 | — |

也可以输入毫米尺寸 + DPI 生成自定义规格。证件照模式下会锁定输出像素与比例；自由裁剪/自定义模式可以按裁剪框输出。

### 压缩与导出

- JPEG / PNG / WebP。
- 画质 30–92%。
- 目标体积（KB）：先用真实 `canvas.toBlob` 做质量二分搜索；仍超标且**不是证件照**时，自动降低输出尺寸重试。
- 输出宽度/高度可改，默认锁定宽高比；超过浏览器上限会自动缩小并提示。
- DPI 元数据：JPEG 写入 JFIF APP0，PNG 在 IHDR 后写入 `pHYs`；WebP 不支持 DPI 元数据。
- 文件名：`lite-photo_<规格>_<宽>x<高>_<YYYYMMDD-HHmm>.<扩展名>`。
- 背景填充只作用于裁剪框留白，不做 AI 抠图或背景替换。

## 隐私与安全

- 图片只在当前页面的 Canvas / `ImageBitmap` 中处理，没有上传接口、没有第三方字体或 CDN。
- 解码时会校验文件魔数，只允许 JPEG / PNG / WebP；HEIC 等格式不支持。
- 导出时 Canvas 重新编码，原图 EXIF（包括 GPS）不会写入导出文件。
- 生产构建自动给本页面注入 CSP（见根目录 `vite.config.ts` 的 `injectImageToolCsp`）。`frame-ancestors` 不能通过 `<meta>` 生效，如需禁止被 iframe 嵌入，请在响应头中配置。

## 浏览器上限

| 项目 | 桌面 | 手机 |
| --- | --- | --- |
| 解码后最长边 | 8192 | 4096 |
| 解码后总像素 | 32 MP | 16 MP |
| 导出最长边 | 8192 | 4096 |
| 导出总像素 | 64 MP | 16 MP |

超出时先降采样源图或自动缩小输出，不阻塞编辑。导出使用主线程 Canvas；超大图导出可能需要数秒。

### 渲染模型

1. 裁剪框以屏幕归一化坐标 `{x, y, w, h}` 保存。
2. `computeView` 根据旋转后的包围盒计算 `fitScale`、`zoom`、原点和裁剪框对应的图片像素区域。
3. 预览：先填充背景，再在屏幕坐标中绘制旋转后的图片。
4. 导出：用屏幕裁剪框映射到输出像素，重新绘制同一套旋转/翻转，因此所见即所得。

## 测试

```bash
# 单元测试（36 个），在仓库根目录执行
npm test

# 浏览器验证：先启动 dev 或 preview，再运行
npm run dev
npm run test:e2e
```

E2E 默认访问 `http://127.0.0.1:5173/lite-joy/image-tool/`；使用预览时通过环境变量覆盖：

```powershell
$env:BASE_URL='http://127.0.0.1:4184/lite-joy/image-tool/'
npm run test:e2e
```

Playwright 使用系统 Edge（`channel: 'msedge'`），需要本机安装 Edge。E2E 覆盖：

- 桌面空状态、导入、一寸规格、自由裁剪、旋转；
- JPEG 295×413 @300 dpi、PNG 295×413 @300 dpi、社保 358×441 @350 dpi；
- 社保 40 KB 目标体积设置；
- 600×800 高熵图在 30 KB 目标下自动缩小、保持比例并写回 300 dpi；
- WebP 导出 RIFF/WEBP 文件头与 `.webp` 扩展名；
- 自定义 35×45 mm、输出宽度联动比例、旋转 90° 后 1200×900 导出；
- 手机 390×844 空状态、导入、单栏 + 底部面板、二寸规格、无横向溢出。

验证产物写入 `test-artifacts/`（已在 `.gitignore` 中忽略）。

## 已知限制 / 后续

- 证件照规格只做常见值参考，不判断具体考试公告。
- 暂未提供撤销/重做；可用「重置裁剪」「重置变换」恢复构图。
- 不做 AI 抠图、换正装、美颜、人脸检测、批量处理；背景色只填充留白。
- 暂未包含 5 寸/6 寸相纸多张证件照排版。
- 暂未包含 PWA / 离线缓存；设计文档中列为 P1。
- 导出为单线程 Canvas，超大尺寸或低端手机可能较慢。
- WebP 不写 DPI；需要打印尺寸时请选 JPEG 或 PNG。
- 为满足目标体积而自动缩小时，面板仍保留用户设定的输出尺寸；实际导出的宽高以成功提示和文件名为准。
- iOS Safari 的异步下载可能改为打开图片预览，可在预览页长按保存；桌面 Chrome/Edge 会直接下载。
